# Contributing to HPC Cluster Administration Documentation

## Found an Error?

Open an issue describing:

- Which document
- What's incorrect
- What should it say (if known)

## Have Improvements?

1. Fork the repository
2. Make your changes
3. Submit a pull request with clear description

## Want to Add Documentation?

We welcome additional production-tested HPC documentation!
Please ensure it includes:

- Real-world deployment context
- Troubleshooting sections
- Clear step-by-step procedures

## Questions?

Open an issue or contact [heramb_k@citilindia.com]
